Controls:

Desktop Controls:

  • W/↑: Swim forward
  • S/↓: Swim backward
  • A/←: Turn left
  • D/→: Turn right
  • Space: Swim up
  • Shift: Swim down
  • I: Look up (camera)
  • K: Look down (camera)
  • J: Look left (camera)
  • L: Look right (camera)
  • T: Toggle Tesla mode (show mobile controls)

Mobile Controls:

  • Left Virtual Joystick: Move around
  • Right Camera Joystick: Control camera view (360° rotation)
  • ↑ Button: Swim up
  • ↓ Button: Swim down
  • Swipe: Look around (alternative)

Tesla Mode:

Press T on desktop to enable Tesla mode, which shows mobile touch controls on large screens for big screen touch interfaces.

How it works

  • All connections are direct peer-to-peer via WebRTC – no central server stores your data.
  • One player hosts; others join using the room code.
  • Up to ~10 simultaneous players are supported.
  • WebRTC requires a modern browser (Chrome 80+, Firefox 75+, Safari 13+).
